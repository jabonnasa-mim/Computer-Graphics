# Multi-Scene OpenGL Graphics Project

A 2D computer graphics project developed using **C++ and OpenGL/GLUT**. The project contains three interactive scenes featuring animated objects, environmental effects, and keyboard controls.

## Project Scenes

### Scene 1: Amusement Park

An animated park environment with a Ferris wheel, swing, moving characters, and weather effects.

### Scene 2: Urban City and Train

A city environment featuring buildings, moving vehicles, pedestrians, and a train.

### Scene 3: Traffic Management

An animated traffic scene featuring moving cars, traffic signals, pedestrians, and a pedestrian crossing.

## Features

* Three scenes in a single application
* Keyboard-based scene switching
* Day and night modes
* Rain, snow, and wind effects
* Animated vehicles and characters
* Interactive traffic signals and pedestrian movement

## Technologies Used

* C++
* OpenGL
* GLUT
* Code::Blocks

## How to Run

1. Install Code::Blocks with a compatible C++ compiler.
2. Configure OpenGL and GLUT.
3. Open `ccc.cbp` in Code::Blocks.
4. Build and run the project.

**Scene switching:** Press `1`, `2`, or `3` to switch between scenes. Press `Esc` to exit.
